# پژوهش و جستجو

دستیار پژوهشگر هوشمند فارسی‌زبان: یک موضوع می‌گیرد، برنامه‌ی پژوهش می‌نویسد، در وب جستجو می‌کند، صفحات را می‌خواند، یافته‌ها را راستی‌آزمایی می‌کند و در پایان یک گزارش فارسی منبع‌دار تحویل می‌دهد. مراحل کار به‌صورت زنده نمایش داده می‌شود.

## پیش‌نیازها

- ویندوز، Python نسخه‌ی ۳٫۱۰ یا بالاتر (بدون Docker)
- یکی از دو گزینه برای مدل زبانی:
  - [Ollama](https://ollama.com) برای اجرای محلی
  - یا یک API سازگار با OpenAI (مثل GapGPT)
- دسترسی به اینترنت برای جستجوی وب (در صورت ،  یا SearXNG شخصی؛ پایین‌تر را ببینید)

## نصب و اجرا

۱. دریافت مدل (فقط برای حالت Ollama):

```
ollama pull qwen3:4b
```

۲. ساخت محیط مجازی و نصب وابستگی‌ها (در پوشه‌ی پروژه، با PowerShell یا CMD):

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

۳. ساخت فایل تنظیمات:

```
copy .env.example .env
```

۴. اجرا:

```
uvicorn app.main:app --reload
```

سپس آدرس http://127.0.0.1:8000 را در مرورگر باز کنید. برای پورت دیگر: `uvicorn app.main:app --port 8080`.

## فونت وزیرمتن

برای اینکه برنامه به CDN وابسته نباشد، فونت باید محلی باشد. دو فایل `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را از مخزن رسمی وزیرمتن (پوشه‌ی `fonts/webfonts`) دانلود کنید و در `static/fonts/` بگذارید. اگر نگذارید، برنامه با Tahoma نمایش داده می‌شود و کار می‌کند.

## تغییر به API سازگار با OpenAI

در `.env` این مقادیر را تنظیم کنید:

```
LLM_PROVIDER=openai_compatible
BASE_URL=آدرس-پایه-API-از-مستندات-سرویس
API_KEY=کلید-شما
MODEL=نام-مدل
```

`BASE_URL` همان آدرسی است که `/chat/completions` به انتهایش اضافه می‌شود. برنامه را دوباره اجرا کنید.

## عمق پژوهش

| عمق | تعداد زیرسؤال |
|---|---|
| سریع | ۲ |
| استاندارد | ۴ |

حداکثر زمان هر پژوهش پیش‌فرض ۵ دقیقه است (`JOB_TIMEOUT_SECONDS`). با تمام‌شدن زمان یا زدن «توقف»، از یافته‌های تأییدشده‌ی موجود گزارش جزئی ساخته می‌شود.

## رفع اشکال

- **«اتصال به Ollama برقرار نشد»**: Ollama را اجرا کنید (`ollama serve`) و مطمئن شوید `OLLAMA_HOST` درست است. نشانگر بالای صفحه وضعیت مدل را نشان می‌دهد.
- **«مدل پیدا نشد»**: دستور `ollama pull qwen3:4b` را اجرا کنید یا `OLLAMA_MODEL` را با مدل نصب‌شده یکی کنید.
- **جستجو جواب نمی‌دهد / **: DuckDuckGo ممکن است از ایران مسدود باشد.  را روشن کنید (httpx متغیرهای `HTTP_PROXY` و `HTTPS_PROXY` را رعایت می‌کند) یا یک SearXNG در دسترس راه بیندازید و آدرسش را در `SEARCH_FALLBACK_URL` بگذارید.
- **کندی مدل**: مدل ۴ میلیارد پارامتری روی CPU کند است. عمق «سریع» را انتخاب کنید، `LLM_TIMEOUT_SECONDS` را بیشتر کنید، یا به API سازگار با OpenAI تغییر دهید. برای مدل‌های qwen3 حالت «تفکر» به‌صورت خودکار خاموش می‌شود.
- **«شواهد کافی پیدا نشد»**: موضوع را دقیق‌تر بنویسید یا عمق «عمیق» را امتحان کنید. برنامه عمداً حدس نمی‌زند.
- **خطای ۴۲۹**: بیش از `MAX_CONCURRENT_JOBS` پژوهش هم‌زمان در حال اجراست.

## نکات فنی

- هر پژوهش حالت، کش صفحات و یافته‌های مستقل خودش را دارد؛ هیچ حالت سراسری مشترکی وجود ندارد.
- یافته‌ای که خروجی راستی‌آزما برایش قابل‌پردازش نبود، هرگز «تأییدشده» حساب نمی‌شود و با برچسب «بررسی‌نشده» می‌ماند.
- خواندن صفحات در برابر SSRF محافظت شده است (localhost، IPهای خصوصی و فایل‌های محلی رد می‌شوند، ریدایرکت‌ها هم بررسی می‌شوند). برنامه را برای استفاده‌ی شخصی روی localhost طراحی کنید و بدون احراز هویت در اینترنت منتشر نکنید.
- فقط گزارش نهایی در SQLite (`data/pazhuhesh_jostejoo.db`) ذخیره می‌شود؛ کارها یک ساعت در حافظه می‌مانند.
